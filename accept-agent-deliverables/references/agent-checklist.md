# Agent 交付验收清单

只选与本次交付相关的条目；每条记录证据位置，不适用时说明原因。

## 一、状态与恢复

- 主流程能到达真实终态，不停留在提案、加载或中间 phase。
- 等待节点恢复后不重复 LLM 调用、写库、发送、扣费或其他副作用。
- 刷新、断线、重连和后端重启按需求恢复会话与待确认状态。
- 重复输入、过期操作和非法 phase 被拒绝或安全忽略。
- 每个 tool call 都有唯一配对结果，包括异常、拒绝、未知工具和超限路径。

## 二、权限与副作用

- 身份来自服务端认证上下文，模型不能指定其他用户身份。
- 读、写、执行风险分级与需求一致。
- 未批准、拒绝和参数变化后均没有未经允许的写入。
- 重复批准、重复点击和重复回调最多产生一次目标副作用。
- 跨用户读写在数据层被隔离，不只靠前端隐藏。
- 工具轨迹能证明“已提案”和“已执行”没有被混为一谈。

## 三、路由与工具选择

至少保留三类真实或可控模型轨迹：

- 应触发：选择预期工具、技能或流程，并携带正确参数。
- 不应触发：相似但无关输入不进入该流程，记录误触发。
- 模糊边界：允许合理替代路径，但不越过禁止工具或安全边界。

最终回答正确但工具路径错误时，不按路由正确验收。模型失败、余额不足和网络异常标为未完成，不直接算作质量失败或通过。

## 四、RAG 与事实性

- 回答中的引用、数字和结论能回溯到原始文档或记录。
- 无结果、低相关、损坏文档与索引不可用有明确行为。
- 数据增删改后索引同步符合需求，失败不会静默展示旧数据为新状态。
- 检索质量使用固定数据集与基线；Hit/Recall/MRR 等指标保留口径。
- 相似但不应命中的负样本不会导致越权或错误引用。

## 五、记忆与上下文

- 长期记忆有来源、重要度、可见和可删除路径。
- 闲聊、模型推测和已注入记忆不会被无门槛反复写回。
- 冲突记忆按契约更新或取代。
- 摘要压缩不破坏 tool call 配对、待确认状态和已完成消息。
- 删除记忆后不再进入后续上下文。

## 六、前端与端到端

- 使用真实浏览器完成主路径，不只检查静态截图。
- 动态页面先观察渲染后的 DOM，再操作语义定位器。
- 覆盖空态、加载、失败、刷新、取消和重复操作。
- 检查控制台业务错误、失败网络请求和关键请求负载。
- 桌面与移动视口无关键遮挡或页面级横向溢出。
- 验收产生的数据可识别、可隔离、可清理；不得删除用户既有数据。

## 七、最终反向检查

签字前尝试推翻自己的结论：

- 哪条核心需求只有作者转述，没有独立证据？
- 哪个正向演示可能掩盖负样本或副作用？
- 哪个数字缺少基线、分母或数据集？
- 哪项修复可能引入相邻回归？
- 哪些内容只能标为未验证？
