# 用药指导技能

## 1. 查药（必做）
用 search_knowledge 检索目标病虫害的「防治药剂」小节与《农药手册》（type_filter="农药手册"），
取得：药剂名、含量剂型、参考亩用量、作用机理、轮换建议。

## 2. 定时机
- 预防性用药需核实实际生育期、病害风险、产品标签及当地植保指导，不能把“雨前打药”当成适用于所有田块的铁律；
- 治疗性用药在发病初/低龄幼虫期，高龄与晚期的防效要如实告知；
- 有天气预报时（MCP 天气）主动核实施药窗口，雷雨、大风或高温时不施药，不能盲目抢雨隙；
- 雨后是否补喷，必须核对具体药剂标签的耐雨时间、实际降雨与施药记录；不得使用固定小时数的一刀切补喷规则，不自行加量、缩短间隔或超过标签次数。

## 3. 核安全间隔期（PHI）
- 距预计收获天数 < 标签 PHI → 明确说"此时不应再施该药"，改推非化学措施；
- 水稻养鱼/虾/蟹田提示禁用与慎用药剂。

## 4. 输出规范
按"药剂（含量剂型，亩用量）→ 施药时机 → 轮换与抗性提示 → PHI 与标签提醒"输出；
多种药剂时给主推+备选，说明选择理由；剂量以产品标签为准的提示**不可省略**。
