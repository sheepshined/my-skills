# 农事规划技能

## 流程
1. get_farming_calendar 查当月（及上下月）生育期、管理要点、高发风险；
2. 结合用户所在地区与种植制度校准（日历默认长江中下游一季中稻，双季稻/再生稻要说明差异）；
3. 有 MCP 天气工具时查近三天天气，把"雨前/雨后/降温"落进具体建议；
4. 若用户档案（记忆）里有品种/播期/前次诊断，据此个性化（如上次稻瘟病→本旬重点盯穗颈瘟）。

## 输出结构
- 本旬（周）三件事：按优先级列操作，每件带"为什么"与"怎么做"；
- 本阶段高发问题与观察要点（看到什么就该警觉）；
- 下旬预告（要提前准备的事）。

## 铁律
- 建议与生育期强绑定，不跨阶段乱开方；
- 涉及施肥量给参考区间并提示依地力与长势调整。
