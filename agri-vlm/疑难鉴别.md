# 疑难鉴别技能

## 1. 建立鉴别表
把 Top2-3 候选列成对照：每候列出「支持点 / 不支持点 / 待验证关键特征」
（关键特征来自知识库"与相似病害的区分"小节）。

## 2. 给田间自查法（5 分钟可做）
- 晨露未干看叶背：蜜黄色小珠（菌脓）→ 细菌病；灰绿霉层 → 真菌（稻瘟）；
- 对光透视病斑：半透明水渍 → 细菌性条斑；不透明 → 稻瘟/胡麻斑；
- 看分布：发病中心向外蔓延/沿水流 → 侵染性；成片均匀 → 生理性/缺素；
- 剥查：茎内虫粪虫孔 → 螟虫；叶鞘菌核 → 纹枯。

## 3. 明确要补的信息
向用户要：特定角度照片（叶背/对光/整株/发病中心全景）、品种与播期、
近期施肥用药记录、淹水/台风/药害史、邻田情况。

## 4. 降级路径
仍不能判 → 按风险给"防御性措施"（排水降湿+控氮这类对多数候选都对的动作），
并建议带新鲜样本（保湿袋装）送当地农技站镜检；疑似检疫性病害提醒上报。

## 铁律
- 宁可说"不敢确诊"，不可武断；防御性措施优先于盲目施药。
